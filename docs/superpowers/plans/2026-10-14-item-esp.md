# Item ESP projection and mode switching implementation plan

**Goal:** Correct vanilla zoom alignment, audit ViewPoint/native ESP, and provide automatic and manual Lua projection selection.

**Architecture:** Keep the existing Lua scanning/UI and C++ JNI matrix bridge. Use current-frame vanilla zoom and item world positions; expose the existing native ViewPoint status once per Lua drawing pass so camera readiness is independent of projection selection.

**Tech stack:** Kahlua Lua, JNI, C++17, local game/JDK25, MSVC v145.

## Constraints

- Feedback reproduces without a 3D mod.
- Automatic switching defaults on. With automatic switching off, the manual 3D toggle selects the projection.
- A loaded but disabled ViewPoint mod uses vanilla projection.
- Selected 3D projection with an unavailable camera skips drawing; manual selection cannot fabricate a missing camera.
- Preserve the user's installed script with a backup and track a canonical copy in Git.
