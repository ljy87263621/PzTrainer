# 模型上色归属、第一人称与独立边缘效果实现计划

**Goal:** 修复原版重叠人物误上色及 ViewPoint 第一人称上色失效，支持仅上色、仅边缘发光和两者同时启用。

**Architecture:** 原版只重放带有实体捕获标记的模型，删除按屏幕包围盒猜测归属的回退。ViewPoint 从模型实例及父实例的所属对象身份匹配当前实体快照，不依赖快照中的高亮标记。上色保持现有材质枚举和配置结构；关闭材质与边缘开关独立生效。边缘从独立轮廓遮罩膨胀并减去内部得到，两条渲染路径共用 GLSL 定义。ViewPoint 材质先进入独立目标，再适配最终画面投影。

**Tech Stack:** 现有 C++17/JNI/OpenGL、Java 17 辅助包、ImGui 自绘控件，无新增用户运行时依赖。当前会话独立执行，保留已有 ESP 与家具目录改动。

- [x] 原版归属：为 `native_model_chams.cpp` 的现有解析函数建立未标记重叠模型回归，确认失败后改为捕获标记匹配；验证未标记玩家跳过、僵尸标记正常。
- [x] ViewPoint 归属：在 `ViewpointModelChamsTest.java` 添加真实模型实例所属对象与父实例测试；辅助类及 JNI 调用传入当前快照身份与分组，验证没有高亮标记的模型仍正常匹配，本地角色和无关模型不匹配。
- [x] 独立边缘：添加共享屏幕合成 shader 和原版/Java 私有遮罩目标；GPU 验证仅边缘时内部不改色、仅上色时外部不发光、两者同时启用以及透明纹理边界。
- [x] 控件与请求：`model_effect_controls.cpp` 提供全身上色和边缘发光独立自绘开关；实体请求与捕获条件接受任一效果，预览同步。沿用 Disabled 材质保存关闭状态，保留历史配置布局。
- [x] 第一人称：在真实 ViewPoint 模型批次测试中使用透视相机、未标记人物实例，并测试最终投影和 GL 状态恢复。
- [x] 执行材质、ViewPoint、ESP、配置相关验证，构建最新 Java 包、DLL 和启动器，检查嵌入资源，交付新的便携验证包与使用说明。
