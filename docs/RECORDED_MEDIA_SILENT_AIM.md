# 录像带生成与静默自瞄检修

## 录像带／CD

旧生成流程只创建 Base.VHS_Retail、Base.VHS_Home 或 Base.Disc_Retail 的基础物品，RecordedMediaIndex 为 -1，未绑定节目内容。新的目录从当前游戏已注册的 RecordedMedia 读取全部有内容的 Retail-VHS、Home-VHS 和 CDs，逐节目显示名称，并加入标题、副标题、作者、媒体 ID、基础物品类型和中英文搜索别名。已按游戏注册的相同类别 Mod 节目也会被纳入；未知类别不会被猜测成 VHS。

- 搜索具体节目名，或“VHS”“录像带”“录影带”“CD”；生成方式选择“游戏原生”。进入存档后若节目尚未出现在列表，使用刷新按钮。
- 指定节目创建正确的基础物品，并在游戏主线程调用 setRecordedMediaData，再把该对象放入背包或地面。数量大于一时逐件创建，各有独立实例。
- 原有通用 VHS/CD 项也会从所属类别中随机选择一个可播放节目。需要指定内容时选择节目名条目。
- 无内容的节目不会入表；找不到节目或目录未加载时明确失败，不再回退生成空白录像带。
- 指定节目条目只支持原生生成；其他载荷方式无法保证携带节目索引，因此在目录和执行入口均排除。
- 目录键 RecordedMedia:<id> 仅用于修改器内部识别。实际物品仍是游戏原生类型，播放、存档和技能内容由游戏媒体数据管理。

## 静默自瞄

发现两个相互关联的设置入口缺陷：目标收集与范围计算未计入仅开启 silent_aim 的情况；实际 AimAtTarget 调用也只接受 automatic_aim 或 magic_bullet。关闭自动瞄准和自动开火后，即使勾选静默自瞄，也可能没有目标快照，更不会启用原生弹道重定向。

现在三个目标收集入口统一识别静默自瞄，实际瞄准入口也在按住原版瞄准键时接受静默模式。未瞄准时清理弹道覆盖。静默模式继续保留角色朝向／准星，不主动进入自动瞄准状态；需要自动抬枪时仍可开启自动瞄准。没有自动开火时显示等待手动开枪的状态。

没有改动配置结构、单机校验、有效目标、距离、骨骼、遮挡和玩家 PVP 条件。俯视与 ViewPoint 共用设置策略；投影和实际弹道接口继续分别处理。

## 验证

设置 PZ_GAME_ROOT 和 PZ_JDK_ROOT（JDK 25）后，在 Windows 开发环境执行：

```powershell
.\scripts\test-recorded-media.ps1
.\scripts\test-rage-targeting.ps1
.\scripts\test-rage-ballistics.cmd $env:PZ_GAME_ROOT $env:PZ_JDK_ROOT
.\scripts\test-rage-fire-jvm.cmd $env:PZ_GAME_ROOT $env:PZ_JDK_ROOT
```

录像带旧路径的空索引以及静默模式的目标收集失败均先复现，再验证修复。真实游戏 JVM 夹具覆盖 55 项媒体检查，C++ 目录夹具覆盖搜索、类别、原生路径限制、纹理模板和去重；Rage 设置矩阵执行当前生产目标收集函数，并确认运行时采用同一策略。原生游戏弹道 DLL 钩子、真实 CombatManager 和 BallisticsController 的枪口方向／命中列表／部位处理测试通过。

这些是隔离的引擎与渲染测试，不等同于实机游玩。此发布没有运行中的游戏可供验收；真实电视播放、用户反馈场景中的俯视角射击、不同武器与低帧率下行为仍需游戏内复测。若仍失效，应同时提供武器、武器预设、自动瞄准／静默／自动开火状态，以及 Rage 状态栏的具体信息。
