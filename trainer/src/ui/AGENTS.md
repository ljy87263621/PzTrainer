# UI 约定

- 新功能优先放进现有对应分类；必要时新建分类或子项，按领域拆分文件，不建立收纳所有功能的杂项页面。
- 新增页面沿用辅助瞄准页的双列紧凑卡片，分组标题放在卡片外；复用 controls/card_layout.hpp。侧栏隐藏滚动条，保留滚轮滚动。
- 不使用 ImGui 默认可见按钮、选择行、标签栏、滑条、复选框或颜色编辑器。优先复用本项目的 components、animated_dropdown、color_picker 和 controls。
- 缺少控件时，在 controls 中实现符合现有暗色圆角、蓝色强调色和弹簧动画的自绘控件。
- ImGui 可以提供布局、命中检测、文本编辑和 IME；输入框的可见外观由项目控件绘制。
- 功能名称不添加“单机”后缀。依据当前会话、服务器权限和目标状态判断可用性，不可用项置灰并显示具体原因；执行层也必须校验相同条件。
